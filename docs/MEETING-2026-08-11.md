## Public Parking Map

A separate meeting will be scheduled. Charity's written notes below establish the redesign direction.

### Organizing principle — rethink color coding

Current legend uses time limit (15min → 4hr → No Limit) as the primary visual encoding. Charity's
feedback:

- The color ramp doesn't communicate **availability windows** — lots that are "evenings and
  weekends only" or "after 11am daily" look the same as always-available lots of the same time limit.
- 15min / 30min / 1hr granularity is too much detail; simplify.
- Proposal: use the **left rail for general notes and parking type** (on-street / lot / covered);
  put the details specific to each lot/zone on the **right side** (detail card).
- Availability-restricted lots (evenings-only, after-11am) should be distinguished visually —
  hatching, a different color, or a pattern.
